# Most Wanted Art

Every card works with a blank MS Paint canvas, so draw in whatever order you like. This list is ordered by how
often you'll see each card and how much it matters to recognise it at a glance.

- **Status:** `npm run placeholders -- --status` lists which files are still blank (it compares each file to the
  untouched canvas).
- **New cards:** `npm run placeholders` creates a blank for any card that has no art file yet. It never
  overwrites a file that exists.
- **Canvas size:** blanks are 320 × 220 px. Any similar landscape image works; it's cropped to fit.
- **Sharing art:** cards can share a file by pointing `artFile` at the same PNG (all seven chump blockers
  share `chump-blocker.png`). Handy for tokens or variants you don't want to draw twice.
